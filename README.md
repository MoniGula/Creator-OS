# Creator OS v3.0 Starter Kit

A human-governed, AI-assisted operating system for turning lived experience, persistent questions, worldview, evidence, and audience dialogue into original work.

## Start here
1. Read `constitution/CREATOR_CONSTITUTION.md`.
2. Review `docs/IMPLEMENTATION_ROADMAP.md`.
3. Add records using the templates in `templates/`.
4. Validate YAML with `python scripts/validate.py`.
5. Run one project through `workflows/full_pipeline.yaml`.

## Non-negotiable architecture
AI proposes. Evidence constrains. The creator interprets and approves.
